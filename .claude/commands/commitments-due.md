# commitments-due

Review outstanding commitments due within fourteen days.

Run `npm run budget -- commitments-due` with the required flags below. All commands accept `--json`. Flags use `--name=value`.

No record selector is required.

Present the result in plain language. List ambiguous candidates and stop for a selector. Drafts stay private. Never send, pay or delete.
