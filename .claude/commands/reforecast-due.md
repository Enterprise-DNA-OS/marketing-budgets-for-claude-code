# reforecast-due

Find forecasts more than fourteen days old.

Run `npm run budget -- reforecast-due` with the required flags below. All commands accept `--json`. Flags use `--name=value`.

No record selector is required.

Present the result in plain language. List ambiguous candidates and stop for a selector. Drafts stay private. Never send, pay or delete.
