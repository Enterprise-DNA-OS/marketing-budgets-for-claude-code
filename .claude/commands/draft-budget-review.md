# draft-budget-review

Draft a branded budget brief without sending anything.

Run `npm run budget -- draft-budget-review` with the required flags below. All commands accept `--json`. Flags use `--name=value`.

Flags: `--budget`.

Present the result in plain language. List ambiguous candidates and stop for a selector. Drafts stay private. Never send, pay or delete.
