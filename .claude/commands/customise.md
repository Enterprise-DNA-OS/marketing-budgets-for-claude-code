# Customise

Read CLAUDE.md and the affected command. Export a private snapshot first. Translate the operator request into a migration in supabase/migrations with the next sequence number. Never rewrite an applied migration. Update the CLI, fixtures, documents, views and this routing library together. Run npm test against a temporary database, inspect the migration, then run npm run migrate on the operator-authorized database. Show the new field or rule in a real read. Preserve amounts, source imports and activity. A compliance-rule change needs a cited source and the operator policy.
