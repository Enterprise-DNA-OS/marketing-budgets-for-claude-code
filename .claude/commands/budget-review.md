# budget-review

Compare approved budgets, forecast spend and remaining headroom.

Run `npm run budget -- budget-review` with the required flags below. All commands accept `--json`. Flags use `--name=value`.

No record selector is required.

Present the result in plain language. List ambiguous candidates and stop for a selector. Drafts stay private. Never send, pay or delete.
