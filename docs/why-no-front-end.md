# Why the database is the product

The recurring work is reviewing budgets, changing forecasts, recording evidence and drafting a weekly brief. The database holds the history, the agent uses one CLI, and read-only HTML shows the result in the business's brand.

A dedicated screen gives mobile entry, drag-and-drop plans, simultaneous edits, attachment previews and account-specific permissions. This base does not provide those. Local PGlite is for one process at a time. PostgreSQL supports shared use, but the connection remains a trusted owner and requires an access design before multiple operators use it. The agent must not invent authentication from an actor name.

Enterprise DNA builds the requested screens, accounting connections and approval workflow into a customised version. The free base remains useful for the budget owner who imports records and runs a weekly review. It does not need a live advertising connection to do those jobs.
